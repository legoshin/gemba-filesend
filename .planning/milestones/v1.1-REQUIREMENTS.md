# Requirements: Gemba Filesend — v1.1 SmoothUI Re-shape

**Defined:** 2026-09-21
**Core Value:** Anyone can share a file securely — encrypted end-to-end, no account, no friction — through a single link.

## Milestone Goal

Re-shape the entire **web** UI (root `src/` Next.js app) onto the **SmoothUI** component language — new geometry (radii/borders/shape) and SmoothUI motion — while keeping the existing colour palette and Public Sans type tokens unchanged, without weakening client-side encryption or breaking web/PWA/TWA parity. SmoothUI is copy-paste source (Motion + GSAP + Tailwind); components are re-styled **in place** on the existing shadcn/Radix layer (no parallel UI kit).

## v1.1 Requirements

### Foundation

- [x] **FND-01**: The `motion` (Framer Motion successor) dependency is installed and available to the web app.
- [x] **FND-02**: A shared SmoothUI shape + motion utility layer exists (reusable radii/border/shape tokens and reusable transition/variant presets) that all re-shaped components draw from — no per-component motion magic numbers.
- [x] **FND-03**: All SmoothUI motion respects `prefers-reduced-motion` — animations degrade to instant/opacity-only when the user opts out.

### Form Controls

- [ ] **FORM-01**: The text Input is re-shaped to SmoothUI geometry with SmoothUI focus/label motion, preserving its Radix/behaviour and validation states.
- [ ] **FORM-02**: Checkbox and RadioGroup are re-shaped to SmoothUI geometry with SmoothUI check/select motion, preserving Radix a11y and keyboard behaviour.
- [ ] **FORM-03**: The Switch/Toggle is re-shaped to the SmoothUI animated-toggle geometry + motion, preserving Radix state and a11y.
- [ ] **FORM-04**: Label and form field grouping/hint styling match the re-shaped controls (consistent shape, spacing, focus ring).

### Buttons

- [x] **BTN-01**: Buttons are re-shaped to SmoothUI geometry (e.g. smooth / clip-corners) with SmoothUI press/hover motion, preserving all existing button ranks/variants and sizes.

### Surfaces

- [ ] **SURF-01**: Card / inset-ring surfaces are re-shaped to SmoothUI geometry with SmoothUI entrance/hover motion.
- [ ] **SURF-02**: Dialog and Sheet/Drawer are re-shaped to SmoothUI geometry with SmoothUI open/close motion, preserving Radix focus-trap and a11y.
- [ ] **SURF-03**: Dropdown-menu and Tabs are re-shaped to SmoothUI geometry + motion (animated tabs indicator), preserving Radix behaviour.
- [ ] **SURF-04**: Badge/Chip, Avatar, and Separator are re-shaped to SmoothUI geometry.

### Feedback & Indicators

- [ ] **FDBK-01**: Toasts (sonner) are re-shaped to the SmoothUI toast geometry + enter/exit motion.
- [ ] **FDBK-02**: The Progress bar is re-shaped to the SmoothUI animated progress geometry + motion.
- [ ] **FDBK-03**: A SmoothUI-style skeleton/loading treatment is applied to loading states.

### File & List

- [ ] **FILE-01**: The file-dropzone is re-shaped to the SmoothUI animated-file-upload geometry + drag/drop motion, preserving multi-file selection and client-side encryption progress.
- [ ] **FILE-02**: File rows / list items (selected files, share results) use SmoothUI animated-list geometry + add/remove motion; any inline images use SmoothUI media treatment.

### Page Motion

- [ ] **MOT-01**: Home, upload, and download pages have SmoothUI section/entrance motion on their primary content.
- [ ] **MOT-02**: A SmoothUI scroll-progress indicator is present on scrollable page(s).

### Shell

- [ ] **SHELL-01**: App-shell/sidebar and mobile-tab-bar are re-shaped to SmoothUI geometry + navigation motion.
- [ ] **SHELL-02**: The theme-toggle is re-shaped to the SmoothUI animated theme-toggle, keeping 3-way light/dark/system control.

### Design System Docs

- [x] **DOC-01**: `design-system/` documents the new SmoothUI shape + motion language (colour/type tokens explicitly unchanged), so the shape/motion decisions are the recorded source of truth.

### Invariants (verified, not weakened)

- [ ] **INV-01**: The colour palette and Public Sans type tokens are unchanged, and light/dark/system theming renders correctly on every re-shaped surface.
- [ ] **INV-02**: The client-side E2E-encryption boundary is intact — the decryption key never reaches the server (upload/download flows still work unchanged).
- [ ] **INV-03**: Web, PWA, and Android TWA parity holds — theme and brand assets render correctly in all three; PWA app-shell cache still valid.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Changing colours, palette, or typography | User directive: keep colours + Public Sans; this milestone changes shape + motion only. |
| Re-shaping `apps/` (WIP monorepo) or `macos/` native app | Scope is the live root `src/` web app; macOS already has its own SmoothUI-based redesign (Phase 8). |
| New features / flows / copy changes | Purely presentational + motion re-shape; no behavioural feature work. |
| Adopting SmoothUI AI/chat/shader/3D component families | Not relevant to a file-share utility; only the UI primitives + motion are in scope. |
| Migrating off Radix to raw SmoothUI source wholesale | Radix a11y behaviour is retained; SmoothUI is applied as shape + motion over the existing components. |
