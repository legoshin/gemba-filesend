<objective>
Install the `motion` dependency and build the shared SmoothUI shape + motion utility layer: a single motion preset module (named transitions + full/reduced variant pairs + a reduced-motion-aware resolver), a shape preset module (radii/ring/clip-corner constants derived from existing Gemba tokens), an app-root `MotionConfig`, and one real consumer (`chip.tsx`) that proves the layer works end-to-end.

Purpose: Later phases (10 component re-shape, 11 page motion) import this vocabulary instead of re-declaring inline spring constants and per-component reduced-motion ternaries. This is the foundation the whole milestone consumes.
Output: `src/lib/motion.ts` (+ test), `src/lib/shape.ts` (+ test), `src/components/motion-config.tsx`, an animated `chip.tsx`, and `motion` in `package.json`.

Scope guard (hard, from CONTEXT.md + RESEARCH.md Architectural Responsibility Map): this plan touches NO colour tokens (`design-system/tokens/colors.css`), NO type tokens, and NO crypto/network/upload/download path (`src/lib/crypto.ts`, `src/lib/storage.ts`, `src/lib/server-storage.ts`, `src/lib/blob-storage.ts`, `src/lib/redis.ts`, `src/app/api/**`). Everything here is client-side visual behaviour only.
</objective>
