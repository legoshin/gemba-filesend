<objective>
Reshape the three Radix portal surfaces (SURF-02 Dialog + Sheet, SURF-03 Dropdown-menu) onto SmoothUI open/close motion. This is the highest-risk group: it swaps Radix's CSS `data-[state=*]:animate-*` unmount for the `forceMount` + `AnimatePresence` pattern, which moves resolved-`open` ownership into the wrapper (RESEARCH Pattern 2, verified from SmoothUI's own dialog source). Radix keeps focus-trap, ESC, outside-click, and all a11y — motion decorates only the Content/Overlay visual layer.

Purpose: Deliver the SmoothUI spring feel without breaking the single live Dialog call site or any Radix behaviour.
Output: forceMount+AnimatePresence Dialog, Sheet (per-side slide), and Dropdown-menu.
</objective>
