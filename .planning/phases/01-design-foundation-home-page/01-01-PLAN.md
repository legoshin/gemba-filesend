<objective>
Wire the Gemba design system into the app as the single source of visual truth and author the dark-mode token layer — all inside `src/app/globals.css` (D-01, D-02, D-08, D-09).

This is the highest-leverage plan in the phase: once `globals.css` re-points Tailwind's `@theme inline` map onto Gemba semantic aliases, every existing utility (`bg-card`, `text-primary`, `rounded-lg`) paints Gemba values with zero call-site churn, and every downstream component/page plan builds on correct tokens.

Purpose: Satisfy DESIGN-01 (tokens wired at app root), DESIGN-02 (semantic aliases, no raw values), DESIGN-03 (Public Sans + type scale), DARK-01 (dark token layer).
Output: A re-pointed, dark-aware `globals.css` importing the Gemba token files.
</objective>
