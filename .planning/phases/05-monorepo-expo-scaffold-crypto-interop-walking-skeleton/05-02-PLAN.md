<interface_contracts>
## Public API the adapters MUST share (D-01) — define these signatures first

@gemba/crypto public async API (identical across crypto.web.ts and crypto.native.ts):
- generateKey(): returns the platform key handle
- exportKeyBase64(key): raw key to Base64URL (the URL-fragment key)
- importKeyBase64(b64): the platform key handle
- encryptPacked(data, key): Promise of Uint8Array = [iv(12)][ciphertext+tag]
- decryptPacked(packed, key): Promise of ArrayBuffer; throws on short payload / bad tag
- sha256Hex(input): Promise of lowercase hex digest
- randomSaltBase64(): 16 CSPRNG bytes to Base64URL
- toBase64Url(bytes) / fromBase64Url(s): pure, byte-only (shared core)

Shared-core internals: a packPayload(iv, ctWithTag) / unpackPayload(packed) pair owning the [iv][ct+tag] byte layout, an encryptPackedWithIv(data, key, iv) for deterministic vector generation, and a per-adapter getRandomBytes(n) primitive (web: crypto.getRandomValues; native: quick-crypto randomBytes) that randomSaltBase64 and IV generation route through — so CSPRNG sourcing never diverges.

@gemba/shared public API:
- MAX_DOWNLOADS, MAX_EXPIRY_MS, MAX_BLOB_BYTES (const)
- validateClientMeta(obj): type guard (the exact predicate from route.ts lines 42-68)
- ClientMeta type (name/type/size/downloadsRemaining/expiresAt)
</interface_contracts>

| Boundary | Description |
|----------|-------------|
