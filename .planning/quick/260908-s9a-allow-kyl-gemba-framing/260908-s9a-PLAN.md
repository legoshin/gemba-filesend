<objective>
Allow the trusted origin https://kyl.gemba.uk to embed send.gemba.uk (apps/web) in an
iframe, while keeping all other cross-origin framing blocked.

Purpose: kyl.gemba.uk is a user-controlled surface that needs to embed the Gemba Filesend
uploader. The current headers deny all framing, so the embed is impossible today.

Output: Two coordinated edits in `apps/web/next.config.ts` — (1) the CSP `frame-ancestors`
directive changes from deny-all to an exact allowlist of `'self' https://kyl.gemba.uk`, and
(2) the `X-Frame-Options: DENY` response-header object is removed because that header can
only express DENY/SAMEORIGIN and cannot allowlist a cross-origin embedder — leaving CSP
`frame-ancestors` as the sole framing-control mechanism. The CSP comment block is updated to
record this framing acceptance.
</objective>
